## Verification Philosophy

Projects are developed with simulation-driven verification using self-checking testbenches, directed testing, randomized stimulus, reference-model checking, protocol checks, assertion-style monitors and functional coverage.

> Note: Projects described as **UVM-style** use an Icarus-compatible verification architecture rather than claiming native IEEE UVM execution. Assertion projects similarly use Icarus-compatible clocked monitors where native SVA support is unavailable.
